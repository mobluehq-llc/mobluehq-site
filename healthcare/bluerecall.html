blueRecall

Reverse impact when an input goes bad

Given a defective reagent lot, a stale calibration, or a software defect, traces the dependency graph in a lab run manifest and signs a per-claim verdict — REVOKED, RERUN-REQUIRED, DEGRADED, UNAFFECTED, or CANNOT-CERTIFY — plus the smallest rerun set that restores what's affected.

Module — in active build
Request a pilot conversation Read the manual
Runs locally · CLI or web UI · Ed25519-signed receipts · no cloud account required
Who it's for

Lab and research-integrity reviewers.

What it is not

No automatic deletion, retraction, notification, or production-system write, and no claim that an unaffected result is scientifically true.

Status, measured

Under active build. See the product's own MVP_STATUS.md for measured, current-state completion.

A signed receipt proves what blueRecall ran and recorded; it does not prove an underlying real-world claim is true. blueRecall does not approve, deny, recommend, pay, retract, or alter anything a named human is responsible for deciding.
