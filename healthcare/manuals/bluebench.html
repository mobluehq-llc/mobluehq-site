blueBench manual

Checks a frozen lab run manifest and its intended conclusion against deterministic license rules before the experiment ships, and signs a LICENSED / QUESTIONABLE / REFUSED / CANNOT-CERTIFY packet with the smallest evidence set needed to clear each open hold.

What this product is and is not

Is: Experiment preflight gate.

Is not: No instrument control, no LIMS write access, no biological truth claim, and no prediction of an experimental outcome.

Who uses it

Lab and research-integrity reviewers.

Getting started — the local demo

From the product's own repository:

make demo
make verify-demo

This runs entirely offline against synthetic fixtures and exits non-zero on any mismatch. It does not connect to any production data source.

What a receipt proves
A signed receipt proves what blueBench ran and recorded; it does not prove an underlying real-world claim is true. Anyone can check the signature offline with the standalone verifier shipped alongside the product, without installing blueBench itself.

FAQ
Does blueBench make the decision for me?

No. No instrument control, no LIMS write access, no biological truth claim, and no prediction of an experimental outcome.

Does blueBench replace the system I already use?

No — it is an overlay. Your existing record system, LIMS, or claims platform stays exactly where it is.
