blueCatch manual

Blinds seeded error cases into a real review queue, imports the reviewer's actual decisions, and signs a scorecard of per-class catch rates with confidence intervals — scoring the process, never a named reviewer.

What this product is and is not

Is: What a review process actually catches.

Is not: Not a live covert-seeding tool, not an employee-surveillance product, and it never touches medical, legal, or financial production records.

Who uses it

Quality and review-assurance leads.

Getting started — the local demo

From the product's own repository:

make demo
make demo-ui   # to see the scored project in the web UI

This runs entirely offline against synthetic fixtures and exits non-zero on any mismatch. It does not connect to any production data source.

What a receipt proves
A signed receipt proves what blueCatch ran and recorded; it does not prove an underlying real-world claim is true. Anyone can check the signature offline with the standalone verifier shipped alongside the product, without installing blueCatch itself.
Known gaps, stated plainly
  • Scores a process, never a named reviewer, by design.
FAQ
Does blueCatch make the decision for me?

No. Not a live covert-seeding tool, not an employee-surveillance product, and it never touches medical, legal, or financial production records.

Does blueCatch replace the system I already use?

No — it is an overlay. Your existing record system, LIMS, or claims platform stays exactly where it is.
