blueBench

Experiment preflight gate

Checks a frozen lab run manifest and its intended conclusion against deterministic license rules before the experiment ships, and signs a LICENSED / QUESTIONABLE / REFUSED / CANNOT-CERTIFY packet with the smallest evidence set needed to clear each open hold.

Module — in active build
Request a pilot conversation Read the manual
Runs locally · CLI or web UI · Ed25519-signed receipts · no cloud account required
Who it's for

Lab and research-integrity reviewers.

What it is not

No instrument control, no LIMS write access, no biological truth claim, and no prediction of an experimental outcome.
