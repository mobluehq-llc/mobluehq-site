Status, measured

What's actually true, per product, per criterion

Three counts, never one score: met, not met, and not measured — reported this way on purpose, because a single percentage hides which kind of unknown you're looking at. Every cell below traces to an exact, dated, quoted line in that product's own status record, a file this site does not edit and did not write. Where that file doesn't clearly say, this page says "not measured" rather than guess.

The nine criteria
  1. Backend/unit test suite passes with 0 failures
  2. Frontend/UI test suite passes
  3. Lint is clean
  4. Typecheck is clean
  5. `make demo` succeeds
  6. `make verify-demo` / tamper battery rejects every tamper vector
  7. A signed customer pilot exists
  8. Live/real PHI has been processed
  9. A non-US or community-edition deployment exists

Applied the same way to every product. A "not measured" criterion isn't a failure — it means the product's own status file doesn't address it either way, so this page doesn't invent an answer.
