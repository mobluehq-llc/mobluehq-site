blueCatch

What a review process actually catches

Blinds seeded error cases into a real review queue, imports the reviewer's actual decisions, and signs a scorecard of per-class catch rates with confidence intervals — scoring the process, never a named reviewer.

Module — in active build
Request a pilot conversation Read the manual
Runs locally · CLI or web UI · Ed25519-signed receipts · no cloud account required
Who it's for

Quality and review-assurance leads.

What it is not

Not a live covert-seeding tool, not an employee-surveillance product, and it never touches medical, legal, or financial production records.

Status, measured

CLI, API, and web UI exist with a 100-item synthetic demo queue. see the status page for exactly what's built.
