See it running, on synthetic data

The hosted blueHealthcare demo runs blueChart and blueClaims (and, as the remaining modules reach demo-ready state, the rest of the suite) against synthetic fixtures — no real patient, member, or claimant data anywhere in it.

Status

The hosted demo is not deployed yet. When it is live, this page will link directly to it. It will be password-protected the same way this section is.

What you'll see, once it's live
  • blueChart's evidence map: a coverage requirement checked against chart evidence, typed into five lanes.
  • blueClaims' Workbench: a claim anchored to policy clauses and record evidence, with typed gaps.
  • The signed receipt behind each, and the offline verifier catching a one-byte tamper.

Every screen and every record shown will be clearly marked synthetic.

Can I run it myself right now?

Not yet, from outside the company. Each product's own repository does have a scripted, deterministic make demo / make verify-demo pair that runs offline against synthetic fixtures — but every one of those repositories is private today, so there is nothing public to clone or install. The manuals describe those commands for reference, not as something you can run without access to the code.

The hosted demo above is the way to see it running without access to any repository. It is not deployed yet; when it is, it will be password-protected the same way this section is.
