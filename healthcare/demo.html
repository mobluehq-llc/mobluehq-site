Download blueHealthcare-demo.dmg

Before you start

  • A Mac with Apple Silicon (M1 or later).
  • Docker Desktop (free) — choose the Apple Silicon version, open it once, and wait until it says it is running.
  • A GitHub username and access token from MOBLUEHQ, sent to you separately. The demo software is private; the token lets your Mac fetch it. Request one.
  • Time on the first start: the download above is small, but the first start fetches a few gigabytes of software. Later starts are quick.

Starting it

  1. Open Docker Desktop and wait until it is running.
  2. Open the downloaded file and double-click Start blueHealthcare Demo.
  3. The first time only, your Mac asks two questions: choose Open (it was downloaded from the internet), then OK (the demo opens a Terminal window to show its progress).
  4. The first time only, enter the GitHub username and access token MOBLUEHQ sent you.
  5. Your browser opens the blueHealthcare launcher. Sign in with the username and password the Terminal window shows you.

When you are done, double-click Stop blueHealthcare Demo, or simply quit Docker Desktop. What you did is kept for next time.

A hosted demo, with nothing to install

A hosted version that runs in your browser — no Docker, no download — is being prepared. It will sit behind a password like this section. Until it is announced here, the download above is the way to see blueHealthcare running.
