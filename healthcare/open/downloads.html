Nothing on this page is downloadable by the public today. A community build now exists internally — make community produces an image containing only the free edition's modules, with a test proving the commercial ones are absent from the artifact, not merely switched off — but the repository and the images are both private, and the published images are single-architecture (arm64 only), measured directly against the published manifest. There is no installer, no public developer kit, and no template pack to download yet — see the roadmap for what's actually built and measured.
How this is meant to reach a clinic

One small server at the clinic — a mini-PC, a laptop, or a cloud server — keeps working when the internet drops. Every other device just uses a web browser against that server: Android phones and tablets, Windows PCs, iPads. Nothing installs per device.

Clinic-server installer

A community build exists today but is private, and its published container images are arm64-only — most clinic servers are x86-64, so a working x86-64 build is a precondition of this being usable, not just a public release of what exists now.
