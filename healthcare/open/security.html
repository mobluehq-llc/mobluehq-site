Security

Reporting a security concern

Open — homeWhyArchitectureSpecContributeFixturesGovernanceSecurityRoadmapCommunity

This project shares a disclosure path with the rest of MOBLUEHQ: security@mobluehq.com, published at /.well-known/security.txt, with the disclosure policy at /trust. That path covers the open spine and the commercial suite alike — there is no separate channel for this section yet.

A concern specific to a jurisdiction pack, the record core, or the verifier is welcome through the same address. Please do not attach or include any real patient, member, claimant, or clinician data in a report — see the fixtures rule, which applies here too.

A dedicated, coordinated-disclosure program (with its own acknowledgements page and a stated response window) is intended once this section has a public repository to run one against — that does not exist yet.
