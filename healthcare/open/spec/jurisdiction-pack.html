The JurisdictionPack interface

Open — homeWhyArchitectureSpecContributeFixturesGovernanceSecurityRoadmapCommunity

Quoted from the platform's own core/jurisdiction/interface.py (a frozen dataclass, 17 fields). This is the whole envelope a jurisdiction pack fills in — see CodingSystem, PrivacyRegime, and FhirProfile for the three pluggable slots referenced below.

FieldTypeWhat it carries
pack_idstrIdentity — a short id like "us" or "xx".
coding_systemCodingSystemThe pluggable coding-vocabulary slot (see the coding-system spec).
privacy_regimePrivacyRegimeThe pluggable privacy-law slot (see the privacy-regime spec).
fhir_profileFhirProfileThe pluggable FHIR R4 profile slot (see the FHIR-profile spec).
compliance_rule_setstrAn opaque, jurisdiction-defined identifier. No compliance-rule engine reads it yet.
policy_pack_formatstrAn opaque, jurisdiction-defined identifier. No policy-pack loader reads it yet.
payer_plan_vocabularytuple[str, ...]e.g. Medicare / Medicaid / commercial / self-pay for the US pack.
currencystre.g. "USD".
localestre.g. "en-US". Nothing in either web app currently reads this field.
date_formatstre.g. "MM/DD/YYYY".
number_formatstre.g. "1,234.56".
data_residency_flagstuple[str, ...]e.g. ("no_residency_requirement",) for the US pack.
secondary_use_allowedboolWhether secondary use of records is allowed under this jurisdiction by default.
deidentification_standardstr | Nonee.g. "HIPAA Safe Harbor" for the US pack.
small_cell_thresholdint | NoneA placeholder small-cell suppression threshold; not a validated compliance value.
data_residency_requiredboolWhether data must stay within the jurisdiction's own borders.
approval_body_typestuple[str, ...]e.g. ("IRB", "Privacy Board") for the US pack.

Two packs are registered today: us (real) and xx (a deliberate, empty stub proving the interface assumes nothing about the US). The loader raises on an unknown pack id — it never silently falls back to us.

This interface existing is not a claim that every product reads from it. See the pack model page for the measured, current wiring state.
