Security & compliance posture

What's true today, stated plainly

This page states only what is measured, not what is aspired to. Where a claim isn't true yet, it says so — including here.

Data

The public demo uses synthetic data only. No real patient, member, or claimant information has been used in any blueHealthcare demo, screenshot, or public material.

No live PHI has been processed by any blueHealthcare product to date, and no customer pilot is signed.

Access control

The blueHealthcare launcher enforces role-based authorization: a session belongs to a named user with a role, and every access is written to an append-only, hash-chained audit log with daily signed checkpoints.

Care-team-scoped access control — restricting a user to records for patients on their own care team — is enforced for a subset of clinical record types today and is being extended to the remaining types. It is not yet enforced across every record type in the system. We report this as a work item, not a finished guarantee, until it measurably covers all of them.

A startup safety guard refuses to run the platform outside a synthetic-fixtures posture while any record type remains unenforced, so a partial rollout cannot silently reach a production-shaped deployment.

Verified access, never data

blueHealthcare sells verified access to review tools — never data. No product in this line has, or plans, any surface for exchanging patient, member, or claimant records for money, in either direction.

Receipts

Every product signs its output with Ed25519 and ships a standalone, dependency-light verifier that checks the signature with no server, no database, and no network connection. Tamper one byte of a signed packet and verification fails — this is a genuinely testable claim, not a marketing one.

A signed receipt proves what the software ran and recorded. It does not prove an underlying real-world claim, conclusion, or coverage determination is true.

What is not true yet
  • No SOC 2 report, HIPAA Business Associate attestation, or equivalent third-party audit exists yet.
  • No signed customer pilot exists yet.
  • No product has processed real PHI.
  • No non-US or community-edition deployment exists yet.
  • Care-team scoping does not yet cover every clinical record type (see Access control above).

We would rather under-claim here than have this page say something the product can't back up.
