WHERE IT ACTUALLY STANDS TODAY

What's built

  • A real cloud-hosted build exists: a container image, a SQL-backed job queue, asynchronous task dispatch with signed callbacks, and cloud document storage for the matters it processes.
  • The hosted deployment is wired so it can reach only MOBLUEHQ's own billing and model-access layer for any model calls it makes — there is no separate path to a model vendor available to it.
  • A local, install-it-yourself CLI has existed and been tested longer than the cloud build, and is the shape used in every completed evaluation to date.

What isn't built yet

  • Not deployed. The cloud build has not been put live for any customer to reach.
  • No accuracy number is published on this page. The evaluation run to date, most recently a six-matter check, is too small a sample to state as a statistic — a bigger, ongoing evaluation is how that gets earned, not asserted.
  • The enterprise on-site option (running on a firm's own hardware) is scoped only, not built.

What every report actually says

  • Each finding is signed and its contents are tamper-evident: any edit after signing breaks the recomputed check.
  • The signature is MOBLUEHQ's own attestation — stated as exactly that, not as a third party vouching for the result.
  • Where a public timestamping service was reached, the report's hash is recorded into a public ledger independent of MOBLUEHQ and the firm — and the report says, per finding, whether that happened or didn't. A confidentiality-first (no outside network calls) run means that step is skipped, and the report says so plainly rather than staying silent about it.
NOT THIS

Not a patentability opinion, and not a substitute for attorney review. blueMoat is not sold or demoed as a tool for drafting or pressing a patent assertion. It is a first-pass screen: it surfaces candidate prior art with a quote tied to its exact source location, or it declines to show a finding it can't tie back that way — the legal judgment about what any of it means is the reviewing attorney's, not the software's.
