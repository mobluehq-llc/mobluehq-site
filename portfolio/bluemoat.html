WHAT IT DOES

Paste a disclosure and blueMoat screens it against prior art, returning a ranked landscape instead of a single yes/no. Two mechanisms do the work, and they are not the same thing: a relevance step narrows a candidate set down to the findings worth a reviewer's time, and a separate anchoring step checks that every quote shown for those findings is an exact, re-findable substring of the source document it's attributed to — never the model's own paraphrase. A finding that can't be anchored is refused rather than shown without a citation a reviewer could not verify.

CLOUD-FIRST, BY DESIGN

blueMoat runs as a cloud service, with an optional on-prem GPU for firms that need one. It does not run on a decentralized mesh of independent machines, and no third party outside MOBLUEHQ witnesses or attests to a blueMoat run — the signature on a receipt is MOBLUEHQ's own, not an outside witness's.

WHERE ANCHORING STANDS TODAY
Anchoring is proven for the standard dispatch path, not for every path yet. Five dispatch drivers — the ones that serve the large majority of runs — anchor every quote before it's shown: an exact-substring check against the stored source text, with a round-trip sanity re-check before a finding is ever marked anchored. Findings dispatched through the separate trench-routing path are not yet anchored against the source document and must be confirmed manually by the reviewing attorney before use; a fix is built but not yet merged into the running service. blueMoat does not currently surface to a reviewer which dispatch path served a given finding, so "you can defend every quote" is not a claim we make for the product as a whole — only for the standard path.
RELEVANCE VS. ANCHORING

blueMoat screens findings for relevance using a single model, then anchors the relevant ones as exact substrings of the source. Both steps are logged in the signed receipt. Relevance scoring is screened, not independently judged — it is not a consensus of multiple models and it is not independently verified, and it must be reviewed by the attorney for importance, the same way any first-pass screen would be.

HOW IT WORKS
1
Submit a disclosure. A description of the invention or the filing under review, run through the cloud service.
2
Relevance screen. Candidate prior art is narrowed to the findings worth attorney time.
3
Anchor or refuse. Each surviving finding's quote is checked as an exact substring of its source and given an offset, or refused outright.
4
Review the landscape. A ranked set of anchored findings, each traceable to its exact place in the source it cites.
5
Signed receipt. The run — inputs, relevance pass, and anchoring outcomes — is logged and signed by MOBLUEHQ.
WHAT IT IS NOT

Not a patentability opinion, not a freedom-to-operate opinion, and not a substitute for attorney judgment. blueMoat is never sold or demoed as a tool for drafting or pressing a patent assertion against another party — it is a landscaping aid for the side doing the reviewing, not an offensive weapon.

THE RECEIPT
A signed receipt proves what blueMoat ran and recorded against which documents; it does not prove a legal conclusion is correct. It does not prove a finding is prior art, that a claim is unpatentable, or that a landscape is complete — those are judgments for the reviewing attorney, not outputs blueMoat produces.
GUIDES
What "anchored" means

An anchored quote is checked as an exact substring of the stored source document — never the model's own summary or paraphrase — and carries the offset where a reviewer can find it in the original. If the quote can't be located this way, the finding is refused instead of shown without a checkable citation.

The trench-path caveat

One internal dispatch path (trench routing) does not yet run findings through the anchoring step. A fix exists but is not yet merged into the running service. Any finding a reviewer suspects came through that path should be confirmed by hand against the source before it's relied on.

Relevance is a screen, not a verdict

The relevance step that narrows candidates down is a single model's pass, not a panel and not a consensus. Treat its ranking as a starting point for attorney review, not as an independently verified judgment.
