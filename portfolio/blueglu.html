blueGlu

A LOCAL-FIRST MAC ASSISTANT · A MOBLUEHQ PRODUCT · IN DEVELOPMENT

blueGlu answers on your Mac by default, on a model that lives on your device. When a question needs more than that model can give, you press a button and send it to a bigger model yourself — the app never decides that for you.

In development Notify me
WHAT IT DOES TODAY

The assistant

  • Runs on-device by default, on your Mac's own hardware.
  • A real routing layer decides which local model handles a given question, weighing cost against a per-question difficulty read — this part is built and wired in, not a stub.
  • An early agent runtime exists underneath: a plan-execute loop with a defined set of tools and a real stopping condition, not just a single request/response call.

Escalation, honestly

  • Escalating to a bigger model is a button you press. There is no automatic elevation today — nothing in the app decides on its own that a question is hard enough to send further. If that's what you're picturing, it isn't built yet.
  • If you already have your own key for a frontier model, escalation goes straight to it. Without one, escalation has nowhere further to go yet.

What isn't ready yet

  • On a brand-new install, the routing layer's own decision table hasn't been populated with a signed, current set of measurements — until that one-time setup step runs, a fresh install's choices are the same simple fallback the app has always shipped with, not the tuned version.
  • The trust key that will let a device verify that decision table is authentic is currently a development placeholder, not the final one — the real key is minted once, in one sitting, before this ships.
  • iOS has no download or install path yet and does not run a real on-device model — Mac is the only real build today.
  • Sharing your machine's spare capacity with the wider network exists as a design, but usage accounting for it is still being built and is not yet something you or anyone else can independently check.
NOT THIS

Not an auto-escalating router. blueGlu's stated goal is a model that quietly gets harder questions in front of something stronger on its own — that half is not built. What exists today is a local-first assistant with a routing layer choosing among on-device models, and a button you press when you want more.
