blueAlibi

A CLAIM-PROVENANCE AUDITOR · A MOBLUEHQ PRODUCT · IN DEVELOPMENT

blueAlibi compares a document against the run trace and capability manifest behind it, and marks every claim with a verdict: what the recorded evidence actually supports, and what it doesn't. It runs entirely on your own machine — nothing about the audit itself leaves it.

In development Notify me
WHAT IT DOES TODAY

The audit

  • Reads a document plus the pipeline's own run trace and capability manifest, and marks each claim with a provenance verdict — what the trace can and can't back up.
  • Ends with a signed receipt. The receipt proves what the software ran and recorded — nothing more.
  • Runs fully offline. No server, no account, no analytics call — the codebase has no outbound network dependency at all, and the product's own interface carries a chip confirming it.

How you'd buy it

  • A one-time-issued licence file you place on disk. Verified entirely offline, with the same signing machinery the audit itself uses.
  • The trust anchor is a public key shipped inside the install — it can confirm a licence was signed by MOBLUEHQ, never mint a new one. There is nothing to phone home to, at purchase or ever after.
  • The licence does not gate the audit. The audit engine behaves identically whether or not a licence is present. Checking for one is an administrative record for support and renewal, not a lock — a locally-editable file could never be a real lock, and pretending otherwise would be dishonest.
  • Pricing is not yet set. blueAlibi runs entirely on your machine and uses none of MOBLUEHQ's own compute, so the mesh-hours pricing the rest of the portfolio uses does not apply here — a different number, still to be decided, will apply when this ships.

What isn't done yet

  • The signing key baked into the current build is a development placeholder. Minting and custodying the real signing key is a one-time, owner-run step that happens immediately before this is actually sold — not something that quietly becomes "production" on its own.
  • No purchase flow is live on this site yet — this page describes the mechanism, not a working checkout.
NOT THIS

Not a global fact-checker, and not a legal or regulatory opinion. blueAlibi audits one thing: whether a document's claims are backed by the specific run trace and capability manifest it was checked against. It says nothing about whether a claim is true in the world — only whether the evidence on hand supports it.
